**Overview**. <br>
This repository contains an Exploratory Data Analysis (EDA) project aimed at understanding the structure, quality, and characteristics of a dataset before applying advanced analytics or machine learning techniques. The analysis includes data cleaning, handling missing values, statistical summaries, and data visualization to uncover patterns, trends, and potential anomalies.

**Learning Objectives**. <br>
Master every major EDA technique from univariate to multivariate
Detect and fix real data quality issues
Apply statistical tests to validate observations
Build interactive visualizations for business storytelling

**Key Analysis Performed**. <br>
Data loading and inspection
Missing value analysis
Duplicate detection and removal
Descriptive statistics
Outlier detection
Correlation analysis
Feature distribution analysis
Data visualization using charts and plots
